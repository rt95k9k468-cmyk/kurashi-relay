# 中継所

ショートカットが健康データを置き、くらしノートが受け取る、小さな郵便受けです。

これを立てると、毎朝の手順が

> ショートカットを走らせる → アプリに戻る → 「コピーしたものを取り込む」を押す

から

> （オートメーションが勝手に走る）→ ダイエットタブを開く

になります。押すボタンが無くなります。

---

## なぜ外を一周させるのか

iPhone の中だけでデータを渡す道は、このアプリの形（Webアプリ）では全部ふさがっています。

| 方法 | 使えるか | 理由 |
|---|---|---|
| URLスキーム（`kurashi://…`） | ✕ | ネイティブアプリの仕組み。Webアプリは名乗れません |
| ユニバーサルリンク | ✕ | 同上。受け取るのはネイティブアプリだけです |
| Web Share Target | ✕ | Safari が実装していません（WebKit bug 194593、いまも open） |
| ショートカットから URL を開く（`?health=…`） | △ | **開くのは Safari のほう**です。ホーム画面のアプリと Safari は保存領域が別なので、入れたデータはホーム画面側から見えません |
| クリップボード | △ | いまの方法。ホーム画面のアプリからは `readText()` が断られるので、毎回「ペースト」を押す必要があります |
| **中継所（これ）** | ○ | 端末の外を一周するので、保存領域の分断を越えられます |

つまり「渡す」のではなく「置いておいて、取りに行く」形にします。

## 何を置くのか

置くのは**手入力とまったく同じ文字**です。

```
day=2026-08-17
steps=8432
sleep=7:12
```

くらしノート側は、受け取った文字列を手入力・貼り付けと**同じ読み取り処理**に渡すだけです。増えるのは入口であって、読み方ではありません。だから中継所は中身を一切見ません。

## どこにあるか

このリポジトリの **`relay/`** です。

```
rt95k9k468-cmyk/kaimono-note      （公開・ブランチ main）
└── relay/
    ├── wrangler.jsonc        設計図（KVは id を書かない＝作らせる）
    ├── worker.js             中継所の本体
    ├── .dev.vars.example     配置のときに RELAY_PATH を尋ねさせるため
    ├── package.json
    ├── worker.test.mjs       ふるまいのテスト（外に出ません）
    ├── embed.js              worker.js をアプリに埋め込み直す
    ├── setup.sh / verify.sh  パソコンがある場合の道具
    └── README.md             これ
```

**GitHubからそのまま配置できる構成にしてあります。** 貼り付けも、KVを手で
作って結ぶ作業も要りません。仕掛けは二つだけです。

- `wrangler.jsonc` の `kv_namespaces` に **`id` を書いていない** → Cloudflare が
  「まだ無いので作る」と解釈して置き場を用意し、id を書き戻します
- `.dev.vars.example` に `RELAY_PATH=` がある → 配置の途中で
  **Secret として尋ねられます**

## 建て方（iPhoneだけ・パソコン不要）

**手順はぜんぶ、アプリの中にあります。** 設定 → ダイエット → **中継所** を開いて
ください。①〜④の順に並んでいて、難しいところは全部ボタンになっています。
ここに書くのはその控えです。

### ① 道（合言葉）をつくる

アプリの **「道をつくる」** を押します。`/kn-…` が出て、クリップボードに乗ります。

iPhoneに `openssl` はありませんし、人が思いつく「適当な文字列」は適当では
ありません（誕生日や名前が混ざります）。だからアプリが作ります——紛らわしい
四文字（`l 1 o 0`）を落とした32文字から16文字ぶん、80ビットです。

### ② 中継所を置く（コピペ不要）

アプリの **「Cloudflareに置く」** を押すと、この `relay/` を指した配置画面が
開きます。

1. Cloudflareに登録（メールアドレスだけ。カードは要りません）
2. GitHubとつなぐ画面が出たら許可する
3. **RELAY_PATH** を聞かれたら、①でコピーした道を**ペースト**
4. **Deploy**

押すと、コードも置き場（KV）も Cloudflare が用意します。

ボタンの行き先はこれです（手で開くなら）:

```
https://deploy.workers.cloudflare.com/?url=https://github.com/rt95k9k468-cmyk/kaimono-note/tree/main/relay
```

**RELAY_PATH を聞かれなかったら**、置いたあとに
**Settings → Variables and Secrets → Add** で、Type を **Secret**、名前を
`RELAY_PATH` にして置いてください（それから **Deploy**）。

**うまくいかないときは、Cloudflareの画面からも同じことができます。**
**Create** → **Import a repository** → `kaimono-note` を選び、
**Root directory** に `relay` と入れて配置します。**あなた自身のリポジトリ**なので、
GitHubをつなげば一覧に出ます。置き場（KV）が自動で用意されなかったときだけ、
**Storage & Databases → KV** で作って、**Settings → Bindings** で `MAIL` という
名前に結んでください。

> **コードを手で貼るやり方は、iPhoneでは勧めません。** 編集画面（Edit code）は
> パソコン向けの部品でできていて、指での「すべてを選択 → ペースト」がうまく
> 効かないことがあります。上の二つは、どちらも貼り付けを必要としません。

### ③ URLをつなげる

Cloudflareの Worker の画面に出ている `…workers.dev` をコピーして、アプリの
**WorkerのURL** の欄に貼り、**「道をつなげる」** を押します。①で作った道が
後ろに付きます。**手で打ち継ぐ必要はありません。**

### ④ 確かめる

アプリの **「中継所を確かめる」** を押すと、その場で一往復して

```
✓ 置けた
✓ 置いたものがそのまま取れた
✓ 渡したら消えた
✓ 道が違えば渡さない
```

を確かめます。通らなければ、**どこで止まったかと、何を直せばいいか**が出ます
（`RELAY_PATH` が無い、KVが結ばれていない、道が違う…）。

確かめる前に郵便受けを空にするので、もう届いていたデータは**捨てずに取り込みます**。

最後に **保存** を押してください。

## パソコンがある場合

```sh
cd relay
./setup.sh          # 道を作って Secret に置き、公開し、確かめ、URLを出す
./verify.sh <URL>   # ④と同じことをコマンドラインから
```

## コードのほうのテスト

```sh
node relay/worker.test.mjs      # → 33 passed
```

KVの偽物を使うので、外に出ません。建てる前にコードの正しさが分かります。

## ショートカットを直す

いまのショートカットの**最後の「クリップボードにコピー」だけ**を差し替えます。前の部分（ヘルスサンプルを検索 → 統計を計算 → テキスト）はそのままです。

1. 「クリップボードにコピー」を削除
2. **「URLの内容を取得」**を追加
3. URL に中継所のURLを入れる
4. その行の **▸（矢印）を開いて**：
   - **方法**：`POST`
   - **本文を要求**：`ファイル`
   - **ファイル**：一つ前の「テキスト」の結果を差し込む

> 「本文を要求」を `JSON` のままにすると、`{"key":"value"}` の形で送られてしまいます。`ファイル` にすると、テキストがそのまま本文になります。

5. 走らせて、**ダイエットタブを開く**。トーストに「中継所：…」と出れば成功です。

### 毎朝、勝手に走らせる

ショートカットアプリの **オートメーション** → **時刻** → 毎朝7時など →
作ったショートカットを選び、**「実行前に尋ねる」をオフ**。

これで、朝のあいだに中継所へ届き、あなたがダイエットタブを開いた時に入ります。

## 気にしておくこと

- **URLが鍵です。** 人に見せるスクリーンショットに写り込ませないでください。漏れたと思ったら、アプリで新しい道を作り、Cloudflare の **Settings → Variables and Secrets** で `RELAY_PATH` を差し替えて **Deploy**、アプリの設定も入れ直します（それだけで古いURLは死にます）。
- **中身は暗号化されません。** 通信は HTTPS ですが、中継所の中では平文です。置かれるのは歩数・睡眠・体重といった数字で、名前も端末IDも含みません。それでも他人のサーバに置きたくないなら、自分のサーバに同じことをする10行を置いても構いません（POSTで保存、GETで返して削除、CORSを許す、それだけです）。
- **取ったら消えます。** 一度受け取ったあとに端末を替えても、その便はもう届きません。次のショートカットの実行を待ってください。
- **置いた直後は、まだ届いていないことがあります。** KV は結果整合で、置いたことが世界中に伝わるまで最大60秒ほどかかります。ショートカットを走らせた**直後**にタブを開くと空のことがあるので、そのときは一度タブを離れて戻ってください。毎朝のオートメーションで走らせるぶんには、まず起きません。
- **同じ便が二度渡ることが、稀にあります。** 消したことの伝わり方も同じだからです。アプリ側は同じ日の同じ種類を差し替えるので、二度入っても記録は増えません。
- **一週間で捨てます。** 取りに来ないまま溜め続けても意味がないので。
- **無料枠。** 一日一往復なら、Workers（10万リクエスト/日）にも KV（1000書き込み/日）にも遠く届きません。

## 壊れていないもの

中継所は**入口が一つ増えるだけ**です。

- 手入力（取り込みシートの①の欄）— そのまま
- コピーしたものを取り込む — そのまま
- ファイルから取り込む — そのまま

中継所を設定していないアプリは、これまでと完全に同じ動きをします。
